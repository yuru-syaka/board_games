 BOARD PIA（boardgamepia.com）  AWS のサービス一覧
 ― ここまでに使い始めたもの・これから使うもの、と理由 ―
 作成日: 2026-10-22
================================================================================

この文書は「AWS のどのサービスを、何のために使っているか（これから使うか）」をまとめたものです。
作業の手順や細かい経緯は docs/roadmap-2026-10-20.txt（手元だけのファイル）を見てください。

■ 読み方
  - 1 章: ここまでに使い始めたサービス（今、動いているもの）
  - 2 章: これから使うサービス（ロードマップのステップ 4〜6 と、その先）
  - 3 章: 使わないと決めたサービス（理由つき）
  - 「どこで作ったか」の欄
      CDK      … infra/lib/ のコード（スタック名も書く）。コードから作り直せる
      手作業   … AWS のコンソール（画面）で設定したもの
  - 料金は 2026-10 時点の目安。実際の金額は Cost Explorer（コスト エクスプローラー）で確かめる

■ 全体の構成（今）
    ブラウザ
     ├ CloudFront → S3                         … サイトとゲーム（boardgamepia.com）
     └ API Gateway（WebSocket）→ Lambda（C#）  … オンライン対戦（wss://ws.boardgamepia.com）
                                → DynamoDB    … 対局中のデータ
    見張り: CloudTrail・GuardDuty・IAM Access Analyzer・CloudWatch のアラーム → SNS → メール
    お金:   Budgets（月 10 USD を超えそうならメール）

 1-1. アカウントの土台（手作業）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ AWS Organizations（組織）                                    料金: 無料
    理由: IAM Identity Center を使うために必要。アカウントをまとめる入れ物。

  ◆ IAM Identity Center（シングルサインオン）                     料金: 無料
    理由: 普段の作業を、ルートユーザー（何でもできる最強のユーザー）ではなく、
          作業用のユーザー（toshiyuki）で行うため。ログインは 8 時間で切れるので、
          パスワードやアクセスキーが漏れても被害が広がりにくい。
    使い方: aws sso login --profile board-game-pia-admin

  ◆ ルートユーザーの多要素認証（MFA）                             料金: 無料
    理由: ルートユーザーが乗っ取られると、すべてを失うため。

  ◆ AWS Budgets（予算）                                           料金: 無料（2 つまで）
    理由: 想定外の請求（設定ミス・いたずら）に、すぐ気づくため。
    設定: monthly-total … 月 10 USD を超えそうならメール。

 1-2. ドメインと証明書
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ Amazon Route 53 … ドメインの登録（手作業）                    料金: 年 15 USD 前後
    理由: boardgamepia.com を自分のものにするため（GitHub Pages の URL から独立）。

  ◆ Amazon Route 53 … ホストゾーンと DNS レコード（CDK: WebStack・GameStack）
                                                                  料金: 月 0.5 USD
    理由: boardgamepia.com・www・ws.boardgamepia.com を、CloudFront と API Gateway に向けるため。
          Google Search Console の所有権の確認（TXT レコード）にも使う（消さない）。

  ◆ AWS Certificate Manager（ACM）… SSL 証明書                    料金: 無料
    - バージニア北部（us-east-1）: boardgamepia.com・www 用（CDK: CertStack）
        理由: CloudFront で使う証明書は、このリージョンに置く決まりのため。
    - 東京: ws.boardgamepia.com 用（CDK: GameStack）
        理由: オンライン対戦の通信（wss://）を暗号化するため。API Gateway は同じリージョンの証明書を使う。

 1-3. サイトとゲームの配信（CDK: WebStack・PlayStack）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ Amazon S3（サイト用のバケット）                               料金: 月数円
    理由: サイトのページと、6 本のゲームのビルド（WebGL）を置く場所。
          直接は公開せず、CloudFront だけが読めるようにしている（OAC）。

  ◆ Amazon CloudFront（配信）                                     料金: 無料枠の範囲（月 1 TB・1,000 万リクエスト）
    理由: 世界中のキャッシュから速く配信するため。HTTPS（TLS 1.2 以上）、www → boardgamepia.com の転送、
          存在しないページの 404、ゲームの Brotli 圧縮ファイルの配信もここで行う。
    付属品:
      - CloudFront Functions（IndexRewrite）… /blog/ → /blog/index.html の読み替えと www の転送
      - レスポンスヘッダーポリシー … セキュリティ用のヘッダー（CSP は「報告のみ」）
      - エラーページ … 403・404 → /404.html

  ◆ AWS Lambda（CDK の BucketDeployment が使う）                   料金: 無料枠の範囲
    理由: cdk deploy のときに、サイトやゲームのファイルを S3 にアップロードし、CloudFront のキャッシュを消すため。
          自分で書いたコードではなく、CDK が用意する部品。

  ◆ AWS Systems Manager Parameter Store（SSM パラメータ）           料金: 無料
    理由: WebStack（サイト）が作ったバケット名と CloudFront の ID を、PlayStack（ゲーム）に渡すため。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1-4. オンライン対戦（CDK: GameStack。2026-10-21〜）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ Amazon API Gateway（WebSocket API）                            料金: 100 万メッセージで約 1 USD
    理由: ブラウザとつながりっぱなしにして、対戦のメッセージをやり取りするため。
          メッセージが届いたときだけ Lambda を呼ぶので、誰も遊んでいなければほぼ 0 円。
    設定: 1 秒 50 件・瞬間 100 件の上限（いたずらで請求が膨らまないように）。
          独自ドメイン ws.boardgamepia.com。
    ※ このアカウントは API Gateway の 12 か月の無料枠がない（最初の 1 件から有料。1 局 0.02〜0.04 円ほど）

  ◆ AWS Lambda（対戦サーバー。C#、.NET 10、arm64）                 料金: 月 100 万回まで無料
    理由: 手が届いたときだけ動いて、ルールで判定し、両者に局面を送るため。
          ルールは Unity と同じ C# のコード（shared/）。サーバーが判定するので、不正やのぞき見ができない。
    設定: メモリ 512 MB、VPC に入れない（NAT ゲートウェイの費用を避ける）。同時実行数の上限は 10（新しいアカウントの値）。

  ◆ Amazon DynamoDB（テーブル 1 つ。オンデマンド）                  料金: 月数円〜数十円
    理由: 接続・待ち行列・ルームコード・対局中のデータ（乱数の種 ＋ 手の一覧）を置くため。
          期限（TTL）で自動的に消えるので、たまり続けない。スタックを消してもテーブルは残す設定。

  ◆ Amazon CloudWatch Logs（対戦サーバーのログ）                   料金: 月 5 GB まで無料
    理由: エラーや動きを調べるため。保存は 1 週間（保管料を抑える）。

  ◆ AWS IAM（ロールと権限）                                        料金: 無料
    理由: Lambda に「このテーブルの読み書き」と「このステージの接続へのメッセージ送信」だけを許すため。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1-5. 安全対策と見張り（CDK: SecurityStack・MonitoringStack）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ AWS CloudTrail（操作の記録）＋ 記録用の S3 バケット             料金: ほぼ無料（記録の保管料だけ）
    理由: 「いつ・誰が・何をしたか」を残すため。乗っ取りや設定ミスの調査に必要。

  ◆ Amazon GuardDuty（不審な動きの検知）                           料金: 月数十〜数百円
    理由: 不正なログインや、怪しい通信を自動で見つけるため。

  ◆ Amazon EventBridge（ルール 1 つ）                              料金: 無料
    理由: GuardDuty が何か見つけたら、メールの通知につなぐため。

  ◆ IAM Access Analyzer（外部に公開されているものの確認）          料金: 無料
    理由: S3 バケットやロールが、意図せず外部から使える状態になっていないかを見張るため。

  ◆ Amazon CloudWatch（アラーム 3 つ。us-east-1）                   料金: 無料（10 個まで）
    理由: サイトの異常に気づくため。
      - CloudFront の 5xx エラー率が 15 分間 5% を超えた
      - 配信量が 1 日で 50 GB を超えた（無料枠を超えるペース）
      - リクエストが 5 分間で 5 万件を超えた（アクセスの急増・攻撃）

  ◆ Amazon SNS（通知。トピック 2 つ）                               料金: 無料（メール 1,000 通まで）
    理由: 上の見張りの結果を、メールで受け取るため（通知先のアドレスは公開しない設定ファイルにある）。

 1-6. 自動デプロイと CDK の土台
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ IAM の OIDC プロバイダーとデプロイ用ロール（CDK: GitHubDeployStack）  料金: 無料
    理由: GitHub Actions から、アクセスキーを保存せずに AWS へデプロイするため。
          GitHub が発行する一時的なトークンを AWS が確かめ、1 時間ほどで切れる鍵を渡す。main ブランチだけ。

  ◆ CDKToolkit（cdk bootstrap。東京と us-east-1）                    料金: 月数円
    理由: CDK がデプロイに使う置き場（S3 バケット・ECR リポジトリ・ロール）。cdk deploy の前提。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 2-1. ステップ 4（壊れにくくする）… 新しいサービスは無し
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ Amazon DynamoDB … 結果用のテーブルを 1 つ足す（4-4）            料金: 月数円
    理由: 対局の結果と棋譜を残すため（ゲーム・時刻・勝敗・終わり方・手数・手の一覧・乱数の種）。
          対局中のデータと違い、期限で消さない。ステップ 5 のレーティング・ランキングの元になる。
    ※ 権限が増えるので、デプロイのときにターミナルで y を押す確認が出る

  ※ 4-2（通信が切れても戻れる）と 4-3（1 手の制限時間）は、今あるサービス（API Gateway・Lambda・DynamoDB）だけで作れた

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 2-2. ステップ 5（ログインと戦績）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ Amazon Cognito（ユーザープール。Lite プラン）                     料金: 月 10,000 人まで無料（期限なし）
    理由: メールアドレスと Google でのログインのため。ログインした人だけ、戦績とレーティングが残る
          （ログインしなくても今までどおり遊べる）。パスワードの保管を自分で作らずに済む。
    ※ 10,000 人を超えた分は 1 人 0.0055 USD。最初から Lite プランで作る
    ※ Google ログインには、Google Cloud 側の設定（OAuth クライアント。無料）も必要

  ◆ Amazon API Gateway（HTTP API）＋ AWS Lambda                         料金: 無料枠〜月数円
    理由: ランキング・プロフィール・戦績のページが、データを読みに来る小さな API のため。
          ページそのものは今のサイトと同じく S3 ＋ CloudFront で配信する。

  ◆ Amazon DynamoDB … ユーザー・レーティングのテーブル                料金: 月数円
    理由: ゲームごとのレーティング（Elo）と、ランキングの元のデータを置くため。

  ◆ Amazon SES（メール送信）… 必要になったら                          料金: 1,000 通で約 0.1 USD
    理由: Cognito の標準のメール送信は 1 日 50 通まで。確認メールがそれを超えるようになったら使う。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 2-3. ステップ 6（仕上げ）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ◆ DynamoDB のポイントインタイムリカバリ（バックアップ）              料金: データが小さいうちは月数円
    理由: 戦績・ユーザーのデータを、誤って消したり壊したりしたときに、前の時点へ戻せるようにするため。

  ◆ AWS Cost Anomaly Detection（コストの異常検出）                     料金: 無料
    理由: 予算アラートより早く、「いつもと違う請求の増え方」に気づくため。

  ◆ Amazon CloudWatch のアラームを足す（対戦サーバー用）               料金: 無料（10 個まで）
    理由: Lambda のエラー・API Gateway の上限に当たった回数が増えたら、メールで気づくため。

 2-4. 人が増えてきたら（必要になったときだけ）

  ◆ CloudFront の定額プラン（Pro、月 15 USD）
    きっかけ: ゲームのダウンロードが月 1 TB を超えそう（1 日 1,000〜3,000 人が目安）
    理由: 月 50 TB まで超過料金なしで、ダウンロードの費用に上限を付けられる。

  ◆ Service Quotas（上限の引き上げの申請）                             料金: 無料
    きっかけ: 同時に遊ぶ人が増え、Lambda の同時実行数 10 や、API Gateway の 1 秒 50 件に当たり始めたら
    理由: 上限を上げないと、遊べない人が出るため。

  ◆ DynamoDB のオートスケーリング（またはオンデマンドのまま）
    きっかけ: 混む時間帯に読み書きが遅れるようになったら
    理由: 人数に合わせて、読み書きの量を自動で増減させるため。


################################################################################
 3. 使わないと決めたサービス
################################################################################

  ◆ Amazon ECS（Fargate）＋ ALB（ロードバランサー）
    理由: 誰も遊んでいなくても月 40〜50 USD かかる。小規模な個人開発では、使った分だけのサーバーレスの方が安い
          （2026-10-21 に方針を変更）。

  ◆ Amazon EC2・Lightsail（仮想サーバー）
    理由: 月 5 USD 前後の固定費に加えて、OS の更新などの管理が必要になる。

  ◆ Docker（と ECR へのイメージ置き場）
    理由: Lambda には .NET のコードをそのまま置けるので不要。

  ◆ NAT ゲートウェイ・VPC
    理由: Lambda を VPC に入れないので不要（NAT ゲートウェイだけで月 40 USD 以上かかる）。

  ◆ AWS WAF（ウェブアプリケーションファイアウォール）
    理由: 月 5 USD 以上の固定費がかかる。今は API Gateway の上限と CloudFront の見張りで足りる。
          人が大きく増えて、攻撃が問題になったら検討する。

  ◆ Photon Cloud（AWS ではない外部サービス）
    理由: 2026-10-21 に、オンライン対戦を自前のサーバーに移したので使わない。
          photonengine.com のアプリの削除は、あなたの操作（数日あとで）。
