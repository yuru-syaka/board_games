# tools/LoadTest — オンライン対戦サーバーの負荷試験（ステップ 6-2）

本番（`wss://ws.boardgamepia.com`）につなぎ、2 人ずつがルームコードで組んで、ゴースト・マルバツを最後まで対局します。

- ルームコードで組むので、ランダムマッチの本物の利用者とは組まれません。
- 手はルール上正しいものからランダムに選び、手番のたびに 0.5〜1.5 秒待ってから打ちます（人が遊ぶ速さに近づけるため）。
- 測るもの: 組めるまでの時間、手を送ってから次の局面が届くまでの時間、エラー。
- 試験の対局も、対局結果のテーブルに「ログインなしの対局」として残ります。試験のあとに、試験の時間帯の分を消してください（下の手順）。

## 使い方

```bash
dotnet run -c Release --project tools/LoadTest -- --pairs 5
```

| 引数 | 既定 | 意味 |
|---|---|---|
| `--pairs` | 5 | 組の数（人数はその 2 倍） |
| `--think-min` / `--think-max` | 0.5 / 1.5 | 1 手を打つまでに待つ秒数 |
| `--ramp` | 5 | 全員がつなぎ終えるまでの秒数（少しずつつなぐ） |
| `--url` | `wss://ws.boardgamepia.com` | 接続先 |

最後に「開始（UTC）」と「終了（UTC）」が出ます。AWS 側の数字（Lambda のエラー・同時実行数、API Gateway の上限に当たった回数）は、この時間帯で確かめます。

## 費用の目安

1 組あたりメッセージは 100 件前後です。50 人（25 組）でも 3,000 件ほどで、1 円もかかりません。

## 試験のあとに結果の行を消す

試験の時間帯（UTC、ミリ秒）に終わった、ログインなしのゴースト・マルバツの結果を消します。消す前に件数を確かめてください。
同じ時間帯に本物のゲストが遊んだ対局があると、それも含まれます。
