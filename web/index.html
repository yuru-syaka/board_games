BOARD PIA

ブラウザですぐ遊べる ボードゲーム作品集

ランキング開発日記

BOARD PIA は、おばけたちが主役のボードゲームを、ブラウザですぐに遊べるサイトです。 今は 2 人で遊ぶゲームが 7 つ、3〜5 人で遊ぶゲームと 2〜4 人で遊ぶゲームが 1 つずつ。すべて無料で、インストールも会員登録もいりません。 ひとりでじっくり遊ぶなら CPU と、だれかと遊ぶならオンライン対戦で。

オンライン対戦で遊ぶ

だれかと対戦

各ゲームの「オンライン対戦」から、ランダムマッチで空いている人と、ルームコードで友だちと遊べます。登録しなくても遊べます。

レートとランキング

ログインしてランダムマッチで遊ぶと、ゲームごとのレートが動き、ランキングに載ります。

通信が切れても安心

通信が切れても、90 秒のうちなら同じ対局に戻れます。1 手には制限時間があるので、相手を待たせ続けることもありません。

BOARD PIA の特徴

短い時間で、深く遊べる

どのゲームも、ルールは数分で覚えられ、1 局は短いもので 1〜3 分、長いものでも 20 分ほどで終わります。 それでいて、相手の手を読む、正体を隠す、競りで駆け引きする、といったボードゲームならではの考えどころを残しました。 各ゲームの「遊び方・ルールを見る」では、ルールと遊び方、勝つためのコツ、よくある質問を載せています。

考える CPU を相手に練習

CPU は、ただ合法な手を選ぶだけではありません。 ゲームに合わせて、先の局面を読んだり、相手のおばけの正体を推理したりして手を選びます。 まずは CPU を相手にルールとコツをつかみ、慣れたらオンライン対戦で人と腕を比べてみてください。

個人で作って、続けて育てる

ゲームの画面もルールの仕組みも対戦サーバーも、すべて個人で一から作っています。 作る中で考えたことや工夫は開発日記に書いています。 不具合やご要望はお問い合わせからお送りください。新しいゲームも順に増やしていきます。
